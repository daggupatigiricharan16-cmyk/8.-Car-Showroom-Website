# AURORA Motors — Car Showroom Website

A responsive, front-end car showroom demo built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

No build tools or dependencies are required. Google Fonts are loaded online; system font fallbacks are included.

## Features
- Responsive showroom landing page
- Six sample car models with locally stored SVG illustrations
- Category filters and model detail dialogs
- Interactive side-by-side specification comparison
- Test-drive request form with browser-side validation and confirmation
- Mobile navigation

## Customize
- Edit model details in the `cars` object in `script.js`.
- Update car cards in `index.html` and matching entries in `script.js`.
- Replace or edit the SVG artwork in `assets/`.
- Adjust colors and layout in `styles.css`.

## Important demo note
All vehicle names, specifications, and prices are fictional sample content for a website demonstration. Prices are indicative placeholders, not verified offers. The test-drive form validates and displays a local confirmation only; it does not transmit personal information. Connect it to a secure backend or CRM before publishing.
